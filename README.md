# zip_shopee
Fuincionamento do sistema:
o sistema conscite em cadastrar o cliente o vendedor com páginas para isso, home e integrantes.
Para fúncionar foi ultilizado o js para criar funções como:
Salvar: para salvar as informações que o úsuario digitar no Realtime Database (banco de dados) do Firebase;
Excluir: para exluir as informações que foram salvas;
Editar: para pegar as informações ja salvas e editar de acordo com oque o usuario deseja;
Cancelar: para cancelar a função editar (parar de editar e voltar como tava antes)
Para isso foi criada uma tabela html com:
Cliente: ID, Nome, Email, Telefone
Vendedor: ID, Nome, Salário, Cargo
